# Artisan Village Website

## Project Overview

Artisan Village is a React-based e-commerce website designed to showcase handcrafted and personalized gifts. The website provides users with an attractive interface to explore products, categories, and special gift collections.

## Features

* Responsive Navigation Bar
* Hero Section
* Product Categories
* Product Cards
* Gift Collections
* Testimonials Section
* Footer
* Responsive Design

## Technologies Used

* React.js
* Vite
* CSS
* JavaScript

## Installation

1. Clone the repository:
   git clone https://github.com/mehakjaiswal67-stack/Artisan-Village-Website.git

2. Navigate to the project folder:
   cd Artisan-Village-Website

3. Install dependencies:
   npm install

4. Run the project:
   npm run dev
